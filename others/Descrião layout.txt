# PROJETO — SITE DE VENDA DE MARMITAS CONGELADAS

## 1. OBJETIVO DO PROJETO

Criar o layout completo de um site profissional, moderno, responsivo e comercial para uma marca de **marmitas congeladas**.

O principal objetivo do site é permitir que o usuário:

* Conheça a marca;
* Entenda como funcionam as marmitas congeladas;
* Consulte o cardápio;
* Visualize informações detalhadas e nutricionais de cada marmita;
* Monte ou escolha combos;
* Simule o preço de um combo personalizado;
* Envie o pedido diretamente pelo WhatsApp;
* Encontre facilmente os canais de contato da empresa.

O site deve transmitir principalmente:

* Qualidade;
* Praticidade;
* Alimentação saborosa;
* Organização;
* Confiança;
* Higiene;
* Profissionalismo;
* Facilidade para fazer pedidos.

O site NÃO deve parecer um e-commerce genérico. A experiência deve ser mais próxima de uma marca moderna de alimentação saudável/congelada, com forte apelo visual para os pratos e uma navegação extremamente simples.

---

# 2. ESTRUTURA GERAL DO SITE

O site terá três páginas principais:

1. HOME
2. CARDÁPIO
3. CONTATO

Além dessas páginas, devem existir componentes e estados complementares:

* Modal de detalhes da marmita;
* Modal/listagem de detalhes dos combos;
* Modal de montagem de combo personalizado;
* Estados de quantidade dos produtos;
* Botões de pedido;
* Estados de hover;
* Estados de botão pressionado;
* Estados de carregamento, quando aplicável;
* Mensagens de confirmação;
* Navegação responsiva;
* Menu mobile;
* Footer global;
* Header global.

Criar o projeto utilizando componentes reutilizáveis para facilitar posteriormente a implementação em HTML, CSS e JavaScript.

---

# 3. DIREÇÃO VISUAL

Criar uma identidade visual moderna e profissional relacionada ao segmento de alimentação.

A aparência deve transmitir:

* Comida gostosa;
* Frescor;
* Praticidade;
* Saúde;
* Qualidade;
* Confiabilidade.

Evitar uma aparência excessivamente corporativa ou tecnológica.

Evitar também excesso de elementos, gradientes exagerados, sombras muito fortes ou excesso de cores.

Priorizar:

* Layout limpo;
* Espaçamento generoso;
* Tipografia moderna;
* Fotografias grandes e apetitosas das marmitas;
* Bordas levemente arredondadas;
* Cards modernos;
* Ícones simples;
* Botões com alto contraste;
* Hierarquia visual clara.

A fotografia das marmitas deve ser um dos elementos visuais mais importantes do site.

---

Criar um pequeno Design System dentro do arquivo do Figma.

# 5. GRID E RESPONSIVIDADE

O layout principal deve ser inicialmente desenvolvido para desktop.

Não utilizar largura de conteúdo ocupando 100% da tela.

Criar um container centralizado com largura máxima aproximada de:

* Desktop: 1200–1280px.

O conteúdo deve permanecer centralizado em telas maiores.

Utilizar margens laterais adequadas.

Criar breakpoints para:

### Desktop

A partir de aproximadamente 1200px.

### Tablet

Aproximadamente 768px até 1199px.

### Mobile

Abaixo de aproximadamente 768px.

O layout deve ser realmente responsivo e não simplesmente uma versão desktop reduzida.

# 26. MODAL — MONTE SEU COMBO

Ao clicar em "Simular preço", abrir um modal grande.

Título:

"Monte seu combo"

Texto:

"Escolha quantas unidades de cada marmita você deseja."

Listar todas as marmitas disponíveis.

Cada item deve possuir:

* Foto pequena;
* Nome;
* Pequena descrição;
* Preço unitário;
* Controle de quantidade.

Controle:

[-] 0 [+]

O botão "+" aumenta a quantidade.

O botão "-" diminui a quantidade.

Não permitir quantidade negativa.

---

### Quantidade total

### Preço

"R$ XX,XX"

"Você economizou XX%"

"Total: R$ XX,XX"

Dar maior destaque aos seguintes elementos:

1. Fotografias das marmitas;
2. Nome dos produtos;
3. Preços;
4. Economia dos combos;
5. Botões de pedido;
6. WhatsApp;
7. Informações essenciais.

Não deixar textos institucionais ocuparem mais espaço visual que os produtos.

---

# 45. RESULTADO ESPERADO

O resultado final deve parecer um site real de uma marca profissional de alimentação, e não apenas um exercício acadêmico.

O layout deve ser:

* Moderno;
* Bonito;
* Comercial;
* Elegante;
* Fácil de navegar;
* Responsivo;
* Acessível;
* Visualmente consistente;
* Preparado para implementação em HTML/CSS/JavaScript.

Priorizar uma excelente experiência de usuário e uma apresentação extremamente atraente das marmitas.

Criar o layout completo de todas as páginas, componentes, modais, estados e versões responsivas, mantendo consistência visual em todo o projeto.
